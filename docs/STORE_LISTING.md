## Full description (both stores)

Rangular Tutorial teaches Rangular the way a good tutorial should:
one short lesson at a time, each with a plain explanation, a Code
block, a live demo you can touch, and a best practice, all on the
same screen.

Rangular is a framework with a simple promise: write Angular, run
native. You write components in TypeScript with HTML templates,
the Angular way, and Rangular compiles them into React Native
code that runs on iOS and Android. This app is built with
Rangular itself, so every screen is proof the compiler works.

The tutorial has 95 lessons in six groups:

- Getting started: your first component, interpolation, event
  binding, and property binding.
- Components and templates: lists, conditionals, inputs and
  outputs, lifecycle, pipes, directives, and theming.
- Forms and interaction: ngModel forms, validators, reactive
  forms, pickers, dialogs, and a complete sign up form.
- Services, routing, and data: dependency injection, shared
  state, the router, and real HTTP requests with honest loading
  and error states.
- The Material pieces: menus, drawers, selects, steppers, grids,
  trees, tables, and more.
- Beyond Angular: bottom navigation, pull to refresh, charts,
  calendars, colour pickers, and the pieces Angular leaves to
  you.

App comforts included: search across all 95 lessons, bookmarks,
a continue row that reopens the last lesson you read, and try it
fields in the most hands on lessons, where your own values drive
the demo live.

Who it is for: Angular developers who want their skills to reach
mobile, mobile developers who already think in components and
templates, and students who learn best by trying each idea on
the same screen where it is explained.

One honest note: lessons 61 to 63 demonstrate HTTP with real
requests to JSONPlaceholder, a public practice API. They send no
personal data.

## Privacy answers

Data collection: none. The app collects no personal data, has no
accounts, no analytics, and no advertising.

On-device state: bookmarks and your place in the lessons are
kept on the device only and keep across restarts. Nothing about your reading leaves the device.

Network: the app makes no network calls of its own. Three
lessons (61 to 63) demonstrate HTTP with GET requests to the
public JSONPlaceholder practice API (jsonplaceholder.typicode.com)
and send no personal data. Two lesson demos (89 and 93) load
practice photos from a public placeholder photo service.

Apple privacy label: Data Not Collected.
Google Play data safety: No data collected, no data shared.
