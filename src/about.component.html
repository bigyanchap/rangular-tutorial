About

Rangular Tutorial

Version 1.0.0. A step by step tutorial app that teaches Rangular: writing iOS and Android apps the Angular way.

Every screen is written in Angular style source and compiled by Rangular into React Native. If a lesson teaches it, this app uses it.

How the tutorial grows

Lessons follow the official Angular documentation, topic by topic. Each topic gets its Rangular equivalent: a short explanation, a code line, and a live demo. Lessons are added in batches of about twenty, and each batch is checked on a real phone before the next one starts.

Made for the stores

This app is being prepared for release on the App Store and Google Play. This first build is the foundation: the splash screen, the lesson engine, and the first five lessons, ready to run in Expo Go.
