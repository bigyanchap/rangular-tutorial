Rangular

Write Angular. Run native.

What is Rangular?

Rangular takes code written the Angular way, components in TypeScript with HTML templates, and compiles it into React Native. One codebase runs as a real app on iOS and Android.

What is this app?

This is the Rangular tutorial. It teaches you Rangular lesson by lesson, the way W3Schools teaches the web, with a short explanation, a Code block, and a live demo you can tap on every screen.

And it is built with Rangular itself. Every screen in this app, including this one, started as Angular code.
